# BedrockBridge Plugins Collection 🎮

Welcome to my custom BedrockBridge plugins repository!
This project contains a collection of custom-built bridge plugins designed to enhance your Minecraft Bedrock Dedicated Server (BDS) and streamline your Discord integration.

> **💡 About BedrockBridge**:

> All plugins in this repository are built on top of the **[BedrockBridge](https://github.com/InnateAlpaca/BedrockBridge)** framework developed by [InnateAlpaca](https://github.com/InnateAlpaca/BedrockBridge).
> Please make sure you have BedrockBridge successfully installed and configured on your server before using these plugins.
> I have also uploaded some plugins developed by [PowerPulse](https://github.com/GERDominik165) which can be find in the Discord Server of Esploratori Development. These plugins are located under the /PowerPulse directory.
